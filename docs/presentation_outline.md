# 論文発表 アウトライン

## 発表構成 (15-20分想定)

---

### 1. 導入 (3分)

**「なぜ腰椎MRIの自動セグメンテーションが重要なのか」**

- 腰痛は世界で最も多い疾患のひとつ (WHO)
- MRIは腰椎診断の中心的ツール
- しかし現状の課題:
  - 医師がMRIを手動で読影 → 時間がかかる
  - 医師間で判断にばらつきがある
  - 椎体・椎間板・脊柱管の境界は複雑
- → **自動セグメンテーション技術が求められている**

---

### 2. セグメンテーションとは何か (2分)

**聴衆にわかるよう視覚的に説明**

- 入力: MRI画像 (グレースケール)
- 出力: 各ピクセルを「椎体」「椎間板」「脊柱管」「背景」に分類
- 図: MRI画像 → カラーマスク → オーバーレイの3枚並べて表示
- 臨床応用: 自動診断支援、手術計画、経過観察

---

### 3. 使用データセット: SPIDER (3分)

**データの質が研究の基盤**

- Nature Scientific Data 2024 に掲載された公開データセット
- 218患者、447 MRIシリーズ (T1 / T2 / T2 SPACE)
- オランダの4病院からマルチセンター収集
- 専門医によるアノテーション (椎体・椎間板・脊柱管)

**データの課題** (論文が解決したポイント):

- マスクに18個の個別ラベル → 4クラスに統合が必要
- 一部のスライスに構造が欠落
- クラス間のピクセル数に大きな不均衡 (背景が大部分)
- 病院間で画質・解像度がバラバラ

---

### 4. 論文のアプローチ: 3本柱 (5分)

**この論文の核心 = データ前処理 x モデル改良 x 損失関数**

#### 柱1: データ前処理の徹底

- 3D MHA → 2D PNG (512x640) への変換
- APTA アルゴリズムで18ラベル → 4クラスに統合
- 4クラス揃わないスライスを除外
- クラス不均衡比率 > 55% のスライスを除外
- 最終的に T1/T2/T2 SPACE 各1000枚 = 計3000枚

#### 柱2: Modified U-Net

- 医用画像の標準アーキテクチャ U-Net をベースに改良
- Leaky ReLU (α=0.1) → dying ReLU問題を回避
- Glorot Uniform初期化 → 学習の安定化
- 512チャネル追加層 → 複雑な特徴の捕捉力向上

#### 柱3: Combined Loss Function

- Focal Loss (γ=4.0): 分類困難なサンプルに集中
- Dice Loss: 予測とGTの重なりを直接最適化
- Combined: 0.6 x Focal + 0.4 x Dice
- → クラス不均衡と境界精度の両方に対応

---

### 5. 結果 (3分)

**定量的に示す**

| 指標              | 本論文     | 既存手法 (nn-UNET) |
| ----------------- | ---------- | ------------------ |
| IVDs Dice         | **0.9688** | 0.86               |
| Vertebrae Dice    | **0.9712** | 0.92               |
| Spinal Canal Dice | **0.9671** | 0.92               |

- 全指標で既存手法を大幅に上回る
- 学習曲線が安定 (100エポック、過学習なし)
- 特に困難な小領域 (脊柱管、椎間板) で大きな改善

**視覚的に示す**

- 予測マスク vs Ground Truth の比較画像
- 失敗例の修正 (論文 Figure 10)

---

### 6. 考察・意義 (2分)

- **データの質がモデルの精度に直結する**ことを実証
  - モデルだけでなく前処理が重要
- 臨床応用に近いレベルの精度 (Dice > 0.96)
- 放射線科医の負担軽減、診断の一貫性向上に貢献

---

### 7. 自分の卒業プロジェクト (2分)

**この論文を出発点に何をするか**

1. **Stage 1**: 論文の再現
   - 同じデータ・同じ手法でコードを実装
   - 同等の精度 (Dice ≈ 0.97) を達成

2. **Stage 2**: 精度の改良
   - アルゴリズムの工夫でDice係数をさらに向上
   - 候補: Attention機構、高度なデータ拡張、損失関数の改良
   - 評価指標: Dice, IoU, ASD, NSD, F1
