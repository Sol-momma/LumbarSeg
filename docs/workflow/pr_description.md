# Pull Request Description Rule

All PR descriptions must be written in English and include these sections:

```markdown
## Why

## What

## How
```

Use the sections as follows:

- `Why`: explain the motivation, problem, or research need.
- `What`: summarize the concrete changes.
- `How`: explain the implementation approach, workflow, or experiment method.

Add these optional sections when useful:

```markdown
## Verification

## Notes
```

Do not omit `Why`, `What`, or `How`.
