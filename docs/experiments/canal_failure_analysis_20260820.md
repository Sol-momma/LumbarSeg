# 脊柱管精度低下の比較分析（2026-08-20）

## 結論

逆平方根クラス重み付きFocal Lossは、脊柱管の見落としを減らした一方で、余分な予測をそれ以上に増やした。固定270枚のスライス平均Diceは`0.785868`から`0.781823`へ低下したため、脊柱管の重みを単純に追加で強める方法は次候補にしない。

ただし、失敗は一様なはみ出しだけではない。小さい脊柱管を含む一部スライスでは候補モデルの予測が縮小または消失しており、画像ごとの不安定さも確認された。次候補は、検証データを固定したまま、境界の誤りを直接抑える損失または小さい脊柱管を保護する学習側の処理を1変更ずつ比較する。

## 画像の目視確認（2026-08-21追記）

SSH復旧後に`06`と`07`の同名PNGをMacへ取得し、同じスライスを左右に並べて確認した。

- `152_t2_SPACE_s042.npz`: baselineにあった小さい脊柱管予測がcandidateでは消失した。
- `152_t2_SPACE_s045.npz`: candidateの脊柱管予測が縮小し、途中で切れた。
- `129_t2_SPACE_s076.npz`: candidateで小さい脊柱管部分の多くが消失した。
- `61_t2_SPACE_s073.npz`: candidateの脊柱管予測がbaselineより広がり、正解範囲を越える部分が増えた。

したがって、数値で確認した「小領域の消失」と「余分な予測の増加」の両方を画像上でも確認した。脊柱管全体のクラス重みを再度増やすのではなく、正解境界の近くだけを重視する第2候補へ進む判断を維持する。

## 次の判断

1. 単純なクラス重み増加は行わない。
2. 第2候補は、正解の脊柱管境界付近にあるFocal Lossだけを相対的に強める。
3. 変更点を1つに限定し、同じ730学習・270検証スライス、batch size 2、seed 42で比較する。
4. 固定検証270枚で再評価し、前景平均`0.9700`とクラス別の論文値を同時に判定する。
