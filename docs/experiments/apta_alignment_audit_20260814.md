# APTAと数値ラベル直接変換の比較監査（2026-08-14）

## 結論

著者公開コードのAPTAを現在の前処理へ全面採用しない。全画素集計では近く見える一方、スライス単位では小さい脊柱管が大きく変形または消失するため、精度向上を期待して置き換えるには危険である。

この監査は学習を行わず、元のMHAを読み取って新しい監査用CSVだけを出力した。既存の前処理済みデータ、採用slice一覧、モデル、評価結果は変更していない。

## 比較条件

- 対象: T2 SPACE 41系列。
- 選択: 各系列から数値ラベル直接変換後に4クラスを含むスライスを等間隔で最大3枚、合計123枚。
- 共通座標: 方向情報から決めた矢状断軸、512×640。
- 基準: 元の整数ラベルを`0 / 1–99 / 100 / 200以上`の4クラスへ直接変換し、最近傍補間。
- 比較: 著者公開コードどおり、スライス単位0–255正規化、線形補間、色域変換、4回の近傍処理、赤クラス消失時のクラス統合。
- 実装識別子: `public_author_code_reconstruction`。論文の未公開部分を含む完全再現とは呼ばない。

## 著者コードどおりの座標を含めた診断

固定X軸、上下反転、高さ620×幅512まで含めた41枚の診断では、直接変換とのDiceは椎骨`0.650954`、脊柱管`0.446137`、椎間板`0.549818`だった。この値にはラベル処理だけでなく軸・向き・サイズの差が含まれるため、APTA単体の性能値として使用しない。
