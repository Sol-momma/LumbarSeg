# T2 SPACE 精度0.97キャンペーン計画

## 結論

論文が報告したクラス別スコアの再現、独自の前景平均`0.9700`、論文手順そのものの再現を、別々に判定する。主要評価はMRI系列を完全分離したhard Diceとし、著者公開コードに近い2Dスライス90/10分割とprobability Diceは原因切り分け専用とする。RTX 3060 Tiは1台なので、tmuxで実験を管理しつつGPU学習は1件ずつ順番に実行する。

## 研究ゴールと社会的貢献

今回のゴールは、単に`0.97`へ近づけることではない。公開情報だけで再現できる範囲と、公開不足で再現できない範囲を分け、同じデータ・分割・指標で改善効果を比較できる実験基盤を作る。その上で、椎間板・椎骨・脊柱管のどこで失敗するかを明らかにし、MRI解析の補助技術として信頼できる条件を示す。

社会的な貢献は次の3点である。

1. 再現できない高精度値をそのまま採用する危険を減らし、医用AI研究の検証可能性を高める。
2. 固定データと自動記録により、小規模な研究環境でも改善手法を公平に比較しやすくする。
3. 特に脊柱管の過剰検出・見逃しを可視化し、将来の読影支援で人が確認すべき失敗条件を示す。

本研究だけで臨床利用可能とは主張しない。外部施設データ、患者単位評価、医師による確認、運用時の安全性評価は別途必要である。

## 合格条件

### 論文スコアの参照値

| クラス | Dice下限 |
| --- | ---: |
| IVDs（椎間板） | `0.9688` |
| Vertebrae（椎骨） | `0.9712` |
| Spinal Canal（脊柱管） | `0.9671` |

### 精度目標の達成

キャンペーンの独自目標は、次を同時に満たした場合だけ成功とする。

1. 3クラスのDice平均（foreground macro Dice）が`0.9700`以上。
2. 3クラスすべてが上表の論文値以上。

Backgroundと既存CSVの`Mean`行は主要判定に使用しない。

論文の3クラス値をすべて上回ったかは`paper_class_targets_met`、前景平均`0.9700`は`foreground_macro_target_met`、両方を満たした状態は`score_target_met`とする。論文値そのものの平均は約`0.969033`なので、論文値の再現だけで前景平均`0.9700`に未達でも矛盾ではない。論文と同じ前処理、画像選別、分割、学習、評価であることまで確認できた状態だけを`paper_protocol_verified=verified`とする。公開情報不足は`unverified`または`blocked`として理由を残す。

## 固定する比較条件

- 対象: T2 SPACE。
- 分割: SPIDER Overview CSVのtraining/validationをシリーズ単位で使用。比較期間中は固定する。
- baseline再実行で確定した検証スライス一覧を`fixed_validation_files.txt`として固定し、全候補を同じ一覧で評価する。filtering/samplingの変更は学習側だけへ適用する。
- 検証画像とマスクの論理内容をSHA-256で固定し、候補の学習開始後・評価開始前に一致を必須確認する。前処理自体を比較する場合は、新しい派生表現でbaselineから別キャンペーンを作り直す。
- 検証用の原画像とマスクは固定し、改良手法で書き換えない。向きの変換が必要な場合は、原本を残した派生データ上で対応する画像とマスクへ同じ決定的変換を適用する。マスク修正は学習側だけへ適用する。
- 入力: 512×640の2D矢状断。
- 初期比較条件: 4クラス必須、不均衡しきい値0.90、最大1,000枚、batch size 2、最大100 epoch、seed 42。
- 固定baseline: foreground macro Dice `0.853805`、Vertebrae `0.916217`、Spinal Canal `0.782836`、IVDs `0.862363`。背景込み旧Meanは`0.886737`。epoch 30で早期終了し、epoch 15の重みを復元した結果を基準にする。
- 比較時は変更点を1種類に限定し、同じ分割、評価コード、seed、出力形式を使う。baseline再実行との差は記録し、無条件に同一結果とみなさない。
- 主要値はIVDs、Vertebrae、Spinal Canalのクラス別Diceとforeground macro Dice。
- IoU、ASD、NSD、Precision、Recall、F1は副次指標として保存する。

## 実験順

| 順番 | 手法 | 目的 | GPU実行 |
| ---: | --- | --- | --- |
| 0 | 現在baselineの再実行 | 新しい判定方法で基準値を固定 | 1件 |
| 1 | 画像方向の監査 | 向き情報と最小軸推定の不一致を学習前に特定 | なし |
| 2 | ラベル品質の監査 | 孤立領域・境界・小面積脊柱管を修正前に定量化 | なし |
| 3 | filtering/sampling比較 | 0.55/0.90と1,000枚選択の影響を分離 | 原則なし |
| 4 | 画像方向の厳密化 | 監査で確認した向きの誤りだけを修正 | 1件 |
| 5 | 学習マスク修正 | 検証マスクを固定し、学習側だけを改善 | 1件 |
| 6 | データ拡張 | 画像方向・位置・濃度変化への頑健性を上げる | 1件 |
| 7 | クラス別損失調整 | 小さい脊柱管と椎間板の学習を強める | 1件 |
| 8 | モデル改良 | 前処理と学習条件で不足する場合のみ検討 | 1件 |

前段で`score_target_met`になった場合は、後続の改良実験を自動停止する。複数変更を同時に入れず、どの変更が精度へ効いたか追跡できる状態を守る。`paper_protocol_verified`は別の再現監査で判定する。

## tmux構成

```text
lumbarseg-goal
├── gpu-queue       学習→評価→目標判定を1件ずつ実行
├── monitor         nvidia-smi、ログ、空き容量を確認
└── cpu-analysis    完了済みCSVの集計だけを並行実行
```

- GPU学習とTensorFlow評価は常に1件だけ実行する。
- CPU処理を並行する場合も別のoutput rootを使用する。
- 長時間実験中は`RECORD_TO_DOCS=0`とし、Git管理下へ自動書き込みしない。
- 出力はキャンペーン日時と実験番号で分離する。
- SSH切断後にtmuxが残ることを短いテストで確認してから開始する。

`training_resume.tsv` は、中断再開時にモデル・最適化状態・完了epochを復元したことと、早期終了・学習率調整の待機回数は復元されないことを分けて記録する。再開実験は候補の救済・調査には使えるが、無中断実験と同一ではないため、最終比較には同じ条件で新規完走する。

各実験で、Git SHA、実コマンド、preset、MRI種類、seed、しきい値、batch/epoch、データ件数、採用slice一覧、train/validation件数、環境、学習ログ、評価CSVを保存する。主要表では`foreground_macro_dice`と背景込みの`legacy_mean_dice`を明確に分ける。

## 停止条件

- `score_target_met`: 後続の改良実験を開始せず正常終了。論文手順の再現完了とは別扱い。
- 目標未達: 次の登録済み手法へ進む。
- 学習失敗、CSV欠損、数値異常: 後続を開始せず異常終了。
- GPU学習が既に動作中: 新しいキャンペーンを開始しない。
- tmux再接続テスト失敗: 長時間実験を開始しない。

## 実装済みの安全装置と入口

1. 同じ推論結果から、スライス平均・全画素集計・シリーズ平均の3方式を保存する。従来の`validation_metrics.csv`は維持し、追加集計は`validation_metrics_aggregations.csv`へ分離する。
2. 数値ラベルから4クラスへの対応、画像方向、画像とマスクの向き情報の一致を、学習前にCSVと確認画像へ出力する。
3. 方向処理は、従来方式・画像情報による自動方式・人が確認した一覧方式を選べる。未確認または曖昧な方向は自動補正しない。
4. 55%は、論文の式と記載値が矛盾しており完全な計算式を確定できない。実験上の代替定義として「背景を除いた3クラスのうち、最大クラスが前景全体に占める割合」を使い、`0.55`ちょうどを残し、`0.55`超を除外する。この代替定義は論文公開原稿の例示3画像（採用2・除外1）の判断と一致するが、「論文式の完全再現」とは扱わない。調査根拠は`paper_filter_definition_20260814.md`に固定する。
5. 0.55/0.90/除外なしの残存数を、学習を行わず同じ前処理済みデータから比較できる。
6. batch size 8は固定8+8件の試験でも8 GiBを超えてOOMしたため、RTX 3060 Tiでは`blocked_hardware`とする。batch size 2へ自動置換せず、別条件として記録する。
7. APTA公開コードをT2 SPACE 41系列・123スライスで直接ラベル変換と比較した。脊柱管のスライスDice中央値は`0.844720`で、3スライスでは脊柱管が消失したため、全面置換は採用しない。詳細は`apta_alignment_audit_20260814.md`に固定する。

## 次の実行順

1. Windows/WSLでデータ監査と55%感度監査を実行する。
2. 方向監査CSVと確認画像を人が確認し、補正対象だけを確定する。
3. batch size 8は既知のOOMとVRAM検査を`blocked_hardware`として記録し、同じ8 GiB GPUで再試行しない。
4. MRI系列分離hard Diceと、著者診断90/10分割・probability Diceの差を測り、未再現の主因が分割・指標・学習条件のどこかを切り分ける。
5. 監査結果から、方向変更とAPTA全面置換は候補外とする。学習側だけのデータ拡張または脊柱管を重視する損失調整から変更点を1つ選び、新しいキャンペーンとして学習する。
6. 固定検証一覧をhard/softおよび3集計方式で評価し、3クラスすべてと前景平均をbaselineと比較する。
