## 3. 読み取り（1回ずつの結果なので暫定）

- 最も高いのは expA（強い増強）で症例 0.9047（+0.0115）。nnU-Net 2D が 0.9023 で続く。
- 脊柱管だけを重くした expB は、椎間板は上がったが脊柱管は 0.8985 と基準より下がった。
- 解像度とエポックを増やした expD はほぼ変化なし。
- 差は 0.01 前後で、seed のばらつきを測らないと有意かどうか言えない。
