# 固定テスト11症例・seed 3回での比較（RunPod RTX 4090、2026-10-21）

すべて実測値です。生の記録は [`experiments/results.jsonl`](../../experiments/results.jsonl) の `sP|…` `sD|…` `sA|…` `sN|nnunet2d|…`（コミット `5a3b23d`、`dirty=false`）にあります。

## 評価のしかた

- **テスト**: Overview CSV の validation にある T2 SPACE 11症例・270スライスに固定しました（`split.sha256=357a8155…`。全条件・全回で一致）。テストの症例は学習にも早期終了にも使っていません。
- **早期終了**: 学習用30症例のうち4症例（`data.inner_val_cases=4`、`inner_val_seed=0`。全条件で同じ症例）を使います。学習は 627 スライス、早期終了は 103 スライスです。
- **主な指標**: 症例ごとの Dice です。前景3クラスの平均を出し、それを症例で平均しています（`eval.dice_average_unit=case`）。
- **回数**: U-Net は `train.seed` を 42・43・44 に変えて3回回しました。nnU-Net は乱数の種を指定できないため、同じ設定で3回回しています。標準偏差は3回の標本標準偏差です。
- **論文条件の基準**（`paper_effective`）: batch 8、γ 0.4、α 0.6、100 epoch です。55%フィルターは文字どおりには使っていません（理由は [paper_filter_check_20261021.md](paper_filter_check_20261021.md)）。論文の数字（0.97 前後）とは直接比べていません。

## 4. 読み取り

- 論文条件の基準は 0.8868 ± 0.0001 で、実装既定（0.8921 ± 0.0018）より 0.0053 低い結果でした。
- 強い増強（0.9027 ± 0.0025）と nnU-Net 2D（0.9019 ± 0.0004）は、どちらも論文条件より約 0.015 高くなりました。3回のばらつき（標準偏差 0.0025 以下）よりはっきり大きい差です。この2つの差 0.0008 はばらつきの範囲内で、どちらが良いとは言えません。
- 脊柱管は、強い増強 0.9128・nnU-Net 0.9131 に対し、論文条件 0.8908・既定 0.8964 でした。改善案ではおよそ 0.02 上がっています。
- 強い増強では 3回とも上限の 100 epoch 近くまで学習が続きました。もっと長く学習すれば伸びる可能性があります。
