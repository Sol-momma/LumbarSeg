## 分かったこと

- 3系列で学習した基準モデルは、T2 SPACE で基準値 0.8868 を上回りました（上の表の差）。学習データが増えたことによる差か、別の要因かは切り分けていません。
- 3条件の中では nnU-Net 2D がどの系列でも最も高く、強い増強が次でした。
