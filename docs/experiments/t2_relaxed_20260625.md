# T2 Relaxed Baseline Experiment - 2026-06-25

## Summary

WSL2 Ubuntu 上の NVIDIA GeForce RTX 3060 Ti で T2 sequence の relaxed filtering baseline を実行した。strict 条件では slice 数が不足して class-wise Dice が不安定だったため、`min_classes` と `imbalance_threshold` を緩めて再学習した。

## Environment

| Item | Value |
| --- | --- |
| OS | WSL2 Ubuntu on Windows |
| GPU | NVIDIA GeForce RTX 3060 Ti |
| Framework | TensorFlow GPU |
| Repository branch | `codex/windows-gpu-runbook` |
| Dataset path | `/mnt/c/Users/ctlab/somomma/DataSet` |

## Command

```bash
python train.py \
  --data_root /mnt/c/Users/ctlab/somomma/DataSet \
  --output_root outputs/t2_relaxed \
  --sequences T2 \
  --batch_size 2 \
  --epochs 100 \
  --min_classes 3 \
  --imbalance_threshold 0.90 \
  --max_slices_per_sequence 0 \
  --force_reprocess

python evaluate.py \
  --data_root /mnt/c/Users/ctlab/somomma/DataSet \
  --output_root outputs/t2_relaxed \
  --min_classes 3 \
  --imbalance_threshold 0.90 \
  --max_slices_per_sequence 0 \
  --model_path outputs/t2_relaxed/checkpoints/best_model.keras
```

## Notes

- T2_SPACE strict filtering retained only 14 slices, so it was not suitable for paper-level reproduction.
- T2 strict filtering also produced unstable validation metrics.
- Relaxed T2 filtering produced 1790 slices and class-wise learning became stable.
- The result is below the target Dice around 0.97, but it is the first usable local GPU baseline.
