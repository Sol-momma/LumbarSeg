# 論文の55%フィルタ定義調査（2026-08-14）

## 結論

論文本文だけから55%フィルタの計算式を一意に再現することはできない。現在の実装は、論文の公開原稿に含まれる採否例3画像をすべて正しく分類できる**実験上の代替定義**であり、論文式の完全再現とは呼ばない。

代替定義は、背景を除いた椎骨・脊柱管・椎間板のうち、画素数が最大のクラスが前景全体に占める割合である。55%ちょうどは残し、55%を超える画像を除外する。

## 確認した一次資料

- 掲載版: [Machine Learning with Applications, DOI 10.1016/j.mlwa.2025.100635](https://doi.org/10.1016/j.mlwa.2025.100635)
- プレプリント: [arXiv:2409.06018](https://arxiv.org/abs/2409.06018)
- 公開LaTeX原稿と例示画像: [arXiv source package](https://arxiv.org/e-print/2409.06018)
- 著者公開コード: [istiak769/Lumbar-Spine-MRI-Segmentation](https://github.com/istiak769/Lumbar-Spine-MRI-Segmentation)

## 本文内の矛盾

| 資料 | クラス重み | 不均衡比 | 問題 |
|---|---|---|---|
| プレプリント | 特定クラス画素数 ÷ 全画素数 | 最大重み ÷ 最小重み | 値は必ず1以上なのに、57%・56%・40%と報告している |
| 掲載版 | 全画素数 ÷ 特定クラス画素数 | 最小重み ÷ 最大重み | 0〜1にはなるが、55%超はむしろクラス間が近い画像になり、「過剰なクラスを除外」という説明と逆になる |

さらに、本文は画像種類全体の比率と1画像ごとの判定を混在させており、背景を含めるか、画像をどう集計するか、最終1000枚をどう選んだかを記載していない。

著者公開コードの`Data Pre-Processing/class weight.py`は、各画像に対してscikit-learnのbalanced class weightを表示するだけである。55%判定、画像除外、最終1000枚の選択処理は公開されていない。

## 例示画像での照合

公開LaTeX原稿に同梱されたFigure 5のPNGをRGB値ごとに数え、背景以外の最大クラス割合を計算した。

| 論文内の例 | 前景最大クラス割合 | 論文の判断 | 代替定義の判断 |
|---|---:|---|---|
| Figure 5(a) | 51.56% | 採用 | 採用 |
| Figure 5(b) | 49.98% | 採用 | 採用 |
| Figure 5(c) | 76.44% | 除外 | 除外 |

この一致は現在方式を採用する根拠にはなるが、一意性の証明にはならない。例えば「前景内の最大画素数と最小画素数の差 ÷ 前景全体」も同じ3画像を分けられる。

## 実験での扱い

1. 現在方式は`paper_filter_proxy`（論文フィルタの代替条件）として記録する。
2. この方式の学習結果を「論文前処理の完全再現」と報告しない。
3. Git SHA、採用slice一覧、train/validation件数、しきい値を各実験に保存する。
4. 著者から除外コードまたは採用slice一覧を入手できた場合だけ、`paper_filter_exact`へ昇格して再評価する。
