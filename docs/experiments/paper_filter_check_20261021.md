# 論文の「55%フィルター」の読み方の確認（2026-10-21）

対象: Ahmed et al., arXiv 2409.06018, 3.2.2 Data Filtration, Step 2。

## 論文の記述（要点）

- 画像ごとの class weight = そのクラスの画素数 / 画像の全画素数（背景も含む式）。
- class imbalance ratio = 最大の class weight / 最小の class weight（「across the dataset」と書かれている）。
- フィルター前の ratio は T1 57%、T2 56%、T2_SPACE 40%。
- 「class weight ratio が 55% を超える画像を除いた」。除外は**画像（スライス）単位**。症例単位で除くという記述はない。
- フィルター後の ratio は T1 55%、T2 55%、T2_SPACE 37%。別の段落では「3.51%、1.79%、7.5%」まで下がったとも書かれ、互いに合わない。
- フィルター後は T1・T2・T2_SPACE ともに 1000 枚（Table 1）。

## こちらのデータで数えた結果（実測）

T2 SPACE、512×640 に変換済みのマスク 5056 枚のうち、4クラスすべてを含むのは 1449 枚（41症例）。この 1449 枚に、読み方ごとに「≤ 0.55 なら残す」を当てた。

| 読み方 | 残る枚数 | 残る症例 |
|---|---|---|
| A 現実装: 前景3クラスの中で最大クラスの割合 | 34 | 7 |
| B 背景も含めた最大クラスの割合 | 0 | 0 |
| C 前景クラスの画像全体に対する割合の最大 | 1449 | 41 |
| D 最小 / 最大（%）が 0.55% 以上 | 1187 | 41 |
| E 前景最大 / 全体最大 | 1449 | 41 |
| F 前景合計の割合 | 1449 | 41 |

データ全体の平均 class weight は 背景 0.8681・椎骨 0.0883・脊柱管 0.0228・椎間板 0.0208。最小 / 最大は 2.4% で、論文の「T2_SPACE 40%」になる読み方は見つからなかった。スライスごとの「前景内の最大割合」は中央値 0.666（5%点 0.566）で、0.55 以下はほとんどない。

## 結論

- 現実装の読み方（A）だと 34 枚しか残らず、論文の「フィルター後 1000 枚」と合わない。論文の記述と照らすと、こちらの読み方が論文の意図と違う可能性が高い。
- ただし論文の数字（40%→37%、3.51% など）はどの定義でも再現できず、正しい定義は論文からは決められない。
- 枚数（1000 枚）を手がかりにすると、フィルターはほとんど何も除いていないはずで、実装の既定値 0.90（2 枚だけ除外し、上限 1000 枚）が論文の結果に最も近い。
- そこで「論文条件の基準」（`paper_effective`）は、学習の設定（batch 8・γ 0.4・α 0.6・100 epoch）だけを論文に合わせ、フィルターは 0.90 のままにした。

集計は保存済みの前処理データ（`filtered_slice_stats.csv` と同じマスク）で行い、データはリポジトリに入れていない。
