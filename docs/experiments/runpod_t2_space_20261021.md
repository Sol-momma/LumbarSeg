# T2 SPACE 5条件の比較と評価単位の比較（RunPod RTX 4090、2026-10-21）

すべて実測値です。生の記録は [`experiments/results.jsonl`](../../experiments/results.jsonl) にあります（コミット `eb5cedc`、`dirty=false`、`profile=lab`、評価は `python -m lumbarseg_cli evaluate`）。
モデル・前処理済みデータ・SPIDER の画像はリポジトリに含めていません。SPIDER は Zenodo 10.5281/zenodo.10159290（CC-BY-4.0）から取得し、md5 は4ファイルとも合格しました。

- 環境: RunPod Secure Cloud の RTX 4090（1台1実験）、イメージは `runpod/pytorch:2.4.0-py3.11-cuda12.4.1`、`tensorflow[and-cuda]==2.17.*`
- 分割: Overview CSV の train/val から T2 SPACE をシリーズ単位で分割（`split=overview_csv_subset`）。検証は11症例・270スライス、学習は30症例・730スライス。
- Dice は前景3クラスの平均（`foreground_macro_dice`）を主指標にしています。「4平均」は背景を含む4クラスの平均です。
