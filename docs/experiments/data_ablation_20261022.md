設定は [baseline_protocol.md](baseline_protocol.md) の基準（focal γ0.4・α0.6、batch 8、100 epoch・早期終了、512×640、増強なし、早期終了用は学習症例から系列ごとに4症例、主指標は症例ごとの Dice（前景3クラス））。seed は 42/43/44。RunPod Secure RTX 4090、コミット `a3fe98d`（`dirty=false`）。数値はすべて実測です。SD は3回の標本標準偏差です。

## 分かったこと

- **画像ごとに分けると症例 Dice が約0.06上がる（0.8868 → 0.9475）**。学習枚数は同じなので、同じ患者が学習とテストの両方にいることによる上振れと考えられます。論文の0.97前後との差の一部は、この分け方で説明できる可能性があります（論文の分け方は未確認）。
- **量をそろえると、3系列混ぜても T2 SPACE のみと同程度かやや低い（0.8847 vs 0.8868）**。bB の +0.009 は主に枚数（627→2212）によるもので、系列の種類が増えたこと自体の効果は今回は見えませんでした。実験2は seed 間のばらつきが大きめ（SD 0.0049）です。
- **T2 SPACE に T2 か T1 を1系列足すと、どちらでも約 +0.007**（約1420枚）。T1 と T2 の差は 0.0006 で、ばらつきの範囲内です。3系列（2212枚）ではさらに約 +0.002 で、伸びは枚数とともに小さくなっています。

## 実行メモ

- 実験1〜3 は各1 pod で seed 42→43→44 を順に実行。途中で箱側の回収記録が失われたため、xI・xQ・xT1 の seed44 は同じコミット・同じ設定で seed44 だけ別 pod（xI44・xQ44・xT144）でやり直しました。表の seed44 はやり直しの値です。
