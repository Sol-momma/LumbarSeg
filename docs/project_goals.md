# LumbarSeg: 目標と計画

## プロジェクト概要

LumbarSeg は、腰椎MRIセグメンテーション論文の再現と改良を行う卒業研究プロジェクト。

**論文**: _Pioneering Precision in Lumbar Spine MRI Segmentation with Advanced Deep Learning and Data Enhancement_ (Ahmed et al., 2025)

---

## 目標 (2段階)

### Stage 1: 論文の再現

論文と同じ手法でコードを実装し、同等の精度を達成する。

| 指標                | 論文の値 (T2 SPACE) | 目標 |
| ------------------- | ------------------- | ---- |
| Dice (IVDs)         | 0.9688              | 同等 |
| Dice (Vertebrae)    | 0.9712              | 同等 |
| Dice (Spinal Canal) | 0.9671              | 同等 |

### Stage 2: 精度の改良

論文のDice係数を**上回る**モデルを構築する。
アルゴリズムの改良・データ拡張・モデル構造の工夫を通じて、評価指標を向上させる。

#### 改良のアプローチ候補

- より深い/広いネットワーク (Attention U-Net, U-Net++, TransUNet等)
- 高度なデータ拡張 (elastic deformation, mixup, cutmix等)
- 損失関数の改良 (Boundary Loss, Tversky Loss等)
- Post-processing (CRF, morphological operations)
- アンサンブル学習

## T1 / T2 / T2 SPACE の違い

### T1強調画像 (T1-weighted)

- **原理**: 縦緩和時間 (T1) の違いを強調
- **見え方**: 脂肪 = 白く明るい、水/CSF = 暗い
- **用途**: 解剖学的構造の把握に最適、骨や脂肪の描出が得意
- **本データ**: 196シリーズ、スライス厚 3.0-4.0mm

### T2強調画像 (T2-weighted)

- **原理**: 横緩和時間 (T2) の違いを強調
- **見え方**: 水/CSF = 白く明るい、脂肪 = やや明るい
- **用途**: 病変の検出に最適 (炎症、浮腫、椎間板変性が明るく見える)
- **本データ**: 210シリーズ、スライス厚 3.0-4.0mm

### T2 SPACE (Sampling Perfection with Application optimized Contrasts using different flip angle Evolution)

- **原理**: T2強調の3D高解像度版
- **見え方**: T2と同様だが、はるかに高い空間分解能
- **特徴**:
  - ほぼ等方性ボクセル (0.90 x 0.47 x 0.47 mm)
  - 通常のT2より解像度が約7倍高い
  - 矢状・軸位・冠状の全方向で詳細に観察可能
  - 撮影時間は長い
- **本データ**: 41シリーズ (UMC病院のみ)

### データセット内での比較

| 特性           | T1                  | T2                  | T2 SPACE              |
| -------------- | ------------------- | ------------------- | --------------------- |
| シリーズ数     | 196                 | 210                 | 41                    |
| ボクセルサイズ | ~3.3 x 0.6 x 0.6 mm | ~3.3 x 0.6 x 0.6 mm | ~0.9 x 0.47 x 0.47 mm |
| 解像度         | 低                  | 低                  | 高                    |
| コントラスト   | 解剖構造重視        | 病変検出重視        | 高解像度T2            |
| 論文のDice     | 0.95-0.96           | 0.93-0.96           | **0.97** (最高)       |

**論文でT2 SPACEが最も高い精度を達成しているのは、高解像度で構造の境界が明瞭だから。**

## 評価指標の整理

### 主要指標: Dice係数 (Dice Coefficient)

```
Dice = 2 * |Prediction ∩ Ground Truth| / (|Prediction| + |Ground Truth|)
```

- 0 (全く重ならない) ～ 1 (完全一致)
- セグメンテーションの標準的指標
- **本プロジェクトの主要目標値**

### その他の指標

| 指標          | 意味                           | 良い方向     |
| ------------- | ------------------------------ | ------------ |
| **IoU**       | 予測とGTの重なり割合           | 高い方が良い |
| **ASD**       | 表面間の平均距離 (mm)          | 低い方が良い |
| **NSD**       | 正規化表面距離                 | 高い方が良い |
| **Precision** | 予測した領域のうち正しい割合   | 高い方が良い |
| **Recall**    | 実際の領域のうち検出できた割合 | 高い方が良い |
| **F1**        | PrecisionとRecallの調和平均    | 高い方が良い |

### Dice vs IoU の関係

```
Dice = 2 * IoU / (1 + IoU)
```

Diceは常にIoU以上の値になる。Dice 0.97 ≈ IoU 0.94。
